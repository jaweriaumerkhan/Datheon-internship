03THE JOURNEY SO FAR

LEARNING · BUILDING · GROWING

One concept at a time.
One project at a time.

I began with the fundamentals and gradually used them in projects of different kinds. Each stage introduced a new way to think: writing logic, structuring larger programs, building for the browser, and connecting digital concepts to hardware. I’m still early in the journey, but I’m learning to turn theory into practice and use each project as a stepping stone.

THE BEGINNING
EDUCATION

Starting Computer Science

FAST-NUCES · Karachi

When I started studying Computer Science, I began building my foundation in programming, logical thinking and problem-solving. I moved from learning basic syntax to understanding how to break a problem into smaller steps and turn an idea into a working program.

Now in my 2nd year, 3rd semester, I am continuing to strengthen my programming fundamentals while exploring object-oriented programming, data structures, algorithms and digital logic.

EARLY HANDS-ON LEARNING
PROGRAMMING FUNDAMENTALS

Hunter Assassin — 2D Game

My step into building interactive projects

One of my early major projects was a 2D Hunter Assassin game. It helped me apply programming fundamentals to player movement, enemy behaviour, collision logic and gameplay. It was a practical way to learn that code is not only about getting the right output—it can also create an interactive experience.

BUILDING STRUCTURE
OBJECT-ORIENTED PROGRAMMING

Flight Reservation System

Organising code with classes and objects

As I progressed to OOP, I built a Flight Reservation System with a graphical interface. This project gave me practice organising a program into classes and objects and modelling features such as reservations in a more structured way.

WEB DEVELOPMENT

Smart Quiz Website

Bringing ideas to the browser

I also created Smart Quiz, a website using HTML, CSS and JavaScript. It includes quiz levels, interactive elements, results and animation. Working on it helped me connect page structure, styling and JavaScript behaviour to create a more complete user experience.

DIGITAL LOGIC DESIGN

Dice Roller

Connecting concepts with hardware

For Digital Logic Design, I worked on a hardware-based Dice Roller using electronic components. It gave me another perspective on computing by connecting digital logic concepts with a physical implementation.

PROFESSIONAL EXPERIENCE
INTERNSHIP · 2 MONTHS

IT Intern

Alkhidmat Foundation

After building experience through academic projects, I completed a two-month internship with Alkhidmat Foundation in the IT domain, focusing on web application development. I contributed to development, testing, refinement and deployment, while learning how to collaborate with a team and work through practical development workflows.

This experience helped me connect what I had been learning in my studies with the process of working on technology in a real organisation. It also gave me a clearer view of the importance of communication, testing, refinement, and teamwork—not just writing code. I finished the internship with more motivation to keep learning and to approach future projects with care and curiosity.
