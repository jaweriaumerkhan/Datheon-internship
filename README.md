# Jaweria Umer — Multi-page Technology Portfolio

A responsive portfolio with a purple technology theme, separate HTML pages, shared CSS and JavaScript, and links to GitHub, LinkedIn, and email.

## Files
- `index.html` — Home and page previews
- `about.html` — Personal story and goals
- `skills.html` — Current skills and learning areas
- `journey.html` — Education, projects, internship, and next steps
- `projects.html` — Academic projects
- `contact.html` — Permanent contact links
- `style.css` — Shared styling and responsive layout
- `script.js` — Navigation and scroll animations

## Run locally
Extract the ZIP, open this folder in VS Code, and run `index.html` with Live Server. Keep the HTML files, `style.css`, `script.js`, and `assets` folder together.
